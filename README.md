# Belita & Theodor — Convite de Casamento

Website estático responsivo, actualizado com o ficheiro `Prob(3).pdf`.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Envie o conteúdo desta pasta para a raiz do repositório GitHub. `index.html` deve ficar na raiz e `assets/` ao lado.
3. No repositório, aceda a **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Seleccione `main` e `/ (root)` e guarde.

## Ajustes desta versão
- Envelope ocupa o ecrã inteiro em telemóveis (`100svh` e `100vw`).
- A imagem do envelope é apresentada em ecrã cheio; em ecrãs maiores preserva-se a imagem completa.
- Ao tocar no selo, a abertura revela o convite e posiciona automaticamente o topo da página, mostrando logo «Com a Bênção de Deus e de seus Pais», sem rolagem manual inicial.
- Conteúdo actualizado a partir do novo PDF `Prob(3).pdf`.
- Botão final abre https://convitin.com.br/matrimonio-belita-theodor//

## Testar
Abra `index.html` num navegador actualizado.
