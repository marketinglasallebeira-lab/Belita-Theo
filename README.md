# Belita & Theodor — Convite de Casamento

Website estático responsivo, preparado para GitHub Pages.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `convite-belita-theodor`.
2. Extraia este ZIP no computador.
3. Envie **o conteúdo desta pasta** para a raiz do repositório. O ficheiro `index.html` deve ficar na raiz e a pasta `assets` deve manter-se ao lado.
4. Faça o commit dos ficheiros.
5. No repositório, aceda a **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Seleccione a branch `main` e a pasta `/ (root)`, depois carregue em **Save**.
8. Aguarde a publicação; o GitHub apresentará o endereço do website na secção Pages.

## Testar

Abra `index.html` num navegador actualizado.

## Estrutura

- `index.html` — página, estilos responsivos e animação de abertura.
- `assets/envelope-cover.jpg` — capa do envelope B&T.
- `assets/convite-atualizado.jpg` — arte integral extraída do PDF **Prob Final.pdf**.
- `.nojekyll` — desactiva o processamento Jekyll.

O botão de confirmação abre:
https://convitin.com.br/matrimonio-belita-theodor//

## Correcção da abertura

Após tocar no selo, o site agora posiciona automaticamente o início do convite no topo do ecrã, mostrando imediatamente a frase «Com a Bênção de Deus e de seus Pais», sem exigir rolagem inicial.
