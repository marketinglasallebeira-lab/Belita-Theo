# Belita & Theodor — Convite de Casamento

Website estático responsivo actualizado com o PDF `Prob(3).pdf`.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Envie o conteúdo para a raiz do repositório. `index.html` deve ficar na raiz e `assets/` ao lado.
3. No GitHub, abra **Settings → Pages**.
4. Escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e guarde.

## Correcções desta versão
- Envelope em ecrã inteiro nos telemóveis.
- Ao tocar no selo B&T, a capa é removida e o convite abre no topo.
- A frase «Com a Bênção de Deus e de seus Pais» foi colocada como texto HTML no primeiro elemento do convite, para aparecer imediatamente, sem depender do carregamento da imagem nem de rolagem.
- A frase foi retirada do topo da imagem para evitar duplicação.
- Botão final abre https://convitin.com.br/matrimonio-belita-theodor//

Abra `index.html` para testar localmente.
