# Convite de Casamento — Belita & Theodor

Website estático responsivo para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo: `convite-belita-theodor`).
2. Extraia este ZIP no seu computador.
3. Abra o repositório e escolha **Add file → Upload files**.
4. Envie os ficheiros e a pasta `assets` que estão dentro desta pasta. O `index.html` deve ficar na raiz do repositório.
5. Clique em **Commit changes**.
6. No repositório, abra **Settings → Pages**.
7. Em **Build and deployment**, seleccione **Deploy from a branch**.
8. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
9. Aguarde a publicação. O GitHub mostrará o endereço público do site na secção Pages.

## Testar localmente

Abra `index.html` num navegador actualizado.

## Conteúdo

- `index.html` — página responsiva e animação de abertura do selo.
- `assets/envelope-cover.jpg` — imagem inicial do envelope B&T.
- `assets/convite-completo.jpg` — arte do convite extraída do PDF actualizado.
- `.nojekyll` — evita processamento Jekyll desnecessário.

O botão final abre `https://convitin.com.br/matrimonio-belita-theodor//`.
